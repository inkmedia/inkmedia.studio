# Ink Media Studio

Ink Media's website, built with Next.js App Router, TypeScript, Tailwind CSS, Framer Motion, Lenis, and React Three Fiber.

## Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Production

```bash
npm run build
npm run start
```

The application is a standard Next.js project and can be deployed to any platform that supports Next.js, including Vercel.
